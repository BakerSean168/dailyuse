## 模块概览

Notification 模块负责系统消息的统一建模、分发和状态管理，避免各业务模块重复建设通知能力。

- 提供统一通知入口，承接业务事件消息。
- 支持按优先级和类型组织通知。
- 管理消息阅读、归档和生命周期状态。
- 支持多终端通知体验的一致性。

## 功能介绍

- 消息分类：区分系统、提醒、业务等不同通知类型。
- 优先级管理：根据紧急程度决定通知策略。
- 状态管理：支持待发送、已发送、已读等状态跟踪。
- 多渠道分发：支持应用内与外部渠道协同触达。
- 消息聚合：减少重复打扰并提升通知可读性。
