## 模块概览

Governance 模块负责沉淀、维护和分发项目规则，帮助团队在开发过程中保持一致的架构与工程实践。

- 提供规则统一入口，减少规范分散问题。
- 支持规则全生命周期管理与持续更新。
- 面向 Web/Desktop 端提供一致的规则浏览体验。
- 为代码评审和技术决策提供可复用依据。

## 功能介绍

- 规则浏览：按标签、状态和优先级查看规则。
- 规则检索：按关键词快速定位目标规则。
- 规则详情：查看规则说明与适用范围。
- 规则追踪：支持规则修订历史查询与审计。
- 规则协同：为团队评审和实践落地提供统一参照。
