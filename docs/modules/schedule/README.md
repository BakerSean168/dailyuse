## 模块概览

Schedule 模块负责统一管理时间事件，是目标、任务与提醒等时间相关业务的协调中枢。

- 提供日程事件的统一组织与展示能力。
- 支持循环事件与跨周期安排。
- 提供冲突识别，帮助用户优化时间分配。
- 支持与目标、任务等模块的时间协同。

## 功能介绍

- 事件管理：支持新增、调整和取消日程事件。
- 视图支持：支持日、周、月等多维度查看方式。
- 循环机制：支持固定频率和可配置的循环安排。
- 冲突检测：识别时间重叠，提示冲突风险。
- 业务关联：支持日程与目标、任务之间的联动。
