## 模块概览

Reminder 模块负责时间驱动的提醒编排，将目标、任务、日程等事件转化为可执行的提醒动作。

- 提供统一提醒模型，覆盖多种业务场景。
- 支持提醒触发前后的状态管理。
- 连接通知模块完成提醒触达。
- 支持提醒节奏优化与用户干预。

## 功能介绍

- 提醒创建：针对目标、任务、日程等对象建立提醒。
- 时间策略：支持准时提醒与提前提醒。
- 状态流转：支持待触发、已触发、已忽略、已取消等状态。
- 操作能力：支持延后、暂停和取消提醒。
- 协同能力：与通知模块联动完成消息发送。
