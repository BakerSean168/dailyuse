## Overview

本模块顾名思义就是目标相关的模块。

然后，它的具体目的是为了帮助用户更好地管理和明确自己的目标，并让用户意识到并激励用户去实现这些目标。 
本项目中使用了 OKR 式的目标管理。因为该总方法能够帮助用户明确目标，并拆分成具体的指向，有助于用户实现。

### 什么是 OKR？

OKR (Objectives and Key Results) 是一种目标管理框架：
- **Objective (目标)**: 定性的、鼓舞人心的目标
- **Key Results (关键结果)**: 定量的、可衡量的结果指标

### 什么是 goal 目标？

Goal 目标是用户设定的具体目标，通常包含以下内容：
- 目标名称
- 目标描述
- 目标状态（进行中、已完成、已放弃）
- 目标截止日期（可以是无期限）
- 目标重要性
- 目标所属的文件夹和标签
- 目标的关键结果列表
- 目标的进度和完成度
- 目标的复盘记录
- 目标的提醒配置

## 模块功能

### **目标管理**

- 创建、编辑、删除目标
- 使用 文件夹、标签 进行目标分类和组织
- 目标状态管理（进行中/已完成/已归档）

### **关键结果管理**

- 为目标添加关键结果（最多5个）
- 设置权重（总和100%）
- 跟踪进度（0-100%）

### **进度计算**

- 关键结果进度计算方式（加权平均、最大值、最小值、最新值、总和等）
- 自动计算加权进度
- 进度可视化
- 完成度分析

### **完成记录**

- 关键结果进度修改时的进度记录（使用 goal-record）

### **智能提醒**

- 截止日期临近提醒
- 进度更新提醒
- 长时间未更新提醒

### **复盘与回顾**

- 提供复盘目标的功能
- goal实现情况的图表数据
- 记录复盘笔记

### **专注模式**

- 选择专注目标，隐藏其他目标
- 自动计算持续时间（所选目标的最晚到期日）
