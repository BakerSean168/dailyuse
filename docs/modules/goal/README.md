## 模块概览

Goal 模块用于管理用户目标与关键结果，帮助用户把长期目标拆解为可追踪、可执行的阶段成果。

- 以目标为核心组织计划、执行与复盘。
- 支持目标状态流转和阶段性跟进。
- 连接提醒、日程等模块形成目标执行闭环。
- 强调进展可视化与可衡量结果。

## 功能介绍

- 目标管理：支持目标创建、编辑、归档与删除。
- 关键结果管理：围绕目标维护多个可衡量结果项。
- 进度跟踪：持续记录并计算目标完成情况。
- 复盘回顾：支持目标执行后的总结与经验沉淀。
- 专注支持：帮助用户聚焦当前优先目标。
