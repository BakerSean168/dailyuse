# AI Agent 工作台产品体验重构计划

## 1. 产品定位

将 Memoflow 从“带 AI 功能的效率工具”重塑为“以 AI Agent 为默认入口的个人目标与知识工作台”。

新的产品心智应该是：

> 用户每天打开应用后，可以直接把想法、困惑、资料和计划交给 Agent。Agent 负责追问、整理、规划、生成结构化草稿，并在用户确认后写入目标、任务、提醒和知识库。

这不是给现有模块额外加一个聊天框，而是把 AI Agent 提升为默认交互入口。目标、任务、知识库、日程等传统模块继续保留，但它们从“用户主动进入的一级入口”转为“Agent 产物的管理、详情和复盘界面”。

## 2. 体验原则

### 2.1 首页就是 Agent

登录后的根路径 `/` 不再展示传统欢迎页。

第一屏改为 AI Agent Workspace：

- 中央是主输入框。
- 左侧是会话与最近 Agent 任务。
- 右侧是可折叠上下文面板。
- 新用户或空会话时提供轻量意图按钮，降低空白感。

推荐第一屏提示：

- 创建一个目标
- 问我的知识库
- 整理一段内容
- 规划今天行动

第一屏不要做营销式介绍，也不要做厚重 Dashboard。用户的第一动作应该是“说出意图”。

### 2.2 聊天不是终点，结构化产物才是价值

普通 AI 产品主要输出文本答案。Memoflow 的差异应该是把聊天结果自然转成个人系统里的结构化对象：

- 目标草稿
- 关键结果
- 任务模板
- 提醒与复盘节奏
- 知识笔记
- 引用来源
- 后续行动建议

Agent 回答后，应尽量给出可确认、可编辑、可落库的结构化结果，而不是停留在一段建议文本。

### 2.3 Agent 模式是用户意图，不是技术菜单

不要让用户理解过多技术模式，例如 `goal mode`、`knowledge-note mode`、`query mode`。

界面表达应改成自然意图：

- 问一问
- 创建目标
- 整理知识
- 问知识库

用户可以点击意图按钮，也可以直接输入自然语言。系统根据输入内容引导用户进入对应 Agent 工作流。

### 2.4 写入动作必须确认

Agent 可以主动生成草稿和计划，但所有业务写入必须经过用户确认。

确认前需要清楚展示：

- 将创建什么对象。
- 对象会写入哪个模块。
- 哪些内容来自用户输入。
- 哪些内容是 AI 补全。
- 用户可以如何编辑、取消或重新生成。

推荐写入链路：

`自然语言意图 -> Agent 澄清 -> 结构化草稿 -> 执行计划 -> 用户确认 -> 写入业务模块 -> 执行结果`

### 2.5 知识问答必须可信

基于个人知识库的回答不能表现得像普通聊天。

Knowledge Agent 的答案必须默认包含：

- 答案正文。
- 引用来源。
- 相关笔记。
- 证据不足提示。
- 打开来源入口。
- 沉淀为知识笔记的入口。

如果没有足够证据，Agent 应明确说“当前知识库证据不足”，而不是编造答案。

## 3. 目标体验形态

### 3.1 整体风格

采用 Claude 式工作台体验：

- 中间是克制、清爽的对话流。
- 右侧承载结构化产物和上下文。
- 左侧承载会话、历史任务和快捷入口。
- 不做花哨英雄页，不做营销式首屏。

视觉目标是“AI 原生应用 + 个人管理软件密度”：

- 像主流 AI 应用一样让输入和对话成为中心。
- 像工作台一样让目标草稿、知识来源、执行计划可以被快速扫描。
- 不用大量装饰卡片堆叠，不让页面显得像功能介绍页。

### 3.2 页面结构

推荐布局：

- 左栏：会话列表、最近 Agent 任务、最近目标、最近知识笔记。
- 主区：AI 对话流。
- 右栏：当前上下文面板。
- 底部：大输入框，包含模型选择、意图选择、发送/停止。

右侧上下文面板根据当前工作流切换：

- Goal Agent：目标草稿、KR 草稿、任务节奏、待确认动作、执行结果。
- Knowledge Agent：引用来源、相关笔记、索引状态、沉淀笔记预览。
- 普通聊天：当前会话摘要、建议下一步动作。

移动端降级为：

- 会话抽屉。
- 主对话。
- 可展开上下文面板。

## 4. 两个核心 Agent

### 4.1 Goal Agent

Goal Agent 的目标不是“生成一个目标”，而是帮助用户建立可执行、可复盘的目标系统。

主流程：

`表达意图 -> Agent 澄清 -> 生成目标草稿 -> 生成执行计划 -> 用户确认 -> 创建目标/KR/任务/提醒 -> 后续复盘`

核心能力：

- 识别目标是否过大、过虚、不可衡量。
- 主动追问 2-4 个关键问题。
- 生成目标、关键结果、任务节奏、复盘频率。
- 在右侧展示可编辑草稿。
- 在确认面板中展示将创建的对象。
- 写入后展示执行结果、失败项和恢复建议。
- 支持后续追问，例如“这个目标本周该怎么推进？”。

推荐交互：

- 用户输入：“我想三个月内把 AI Agent 能力用到我的项目里。”
- Agent 先判断是否需要澄清。
- 澄清完成后生成目标草稿。
- 用户在右侧修改目标名称、KR、时间范围和复盘节奏。
- Agent 生成“将创建目标、2 个 KR、3 个任务模板、每周复盘提醒”的执行计划。
- 用户确认后写入。
- 写入完成后，主对话展示结果，右侧展示执行时间线。

### 4.2 Knowledge Agent

Knowledge Agent 的目标是让用户的个人知识库变成可问答、可整理、可复用的知识资产。

主流程：

`提问/输入材料 -> 检索个人知识库 -> 带引用回答 -> 生成/更新知识笔记 -> 保持索引可用`

核心能力：

- 默认基于个人知识库回答。
- 答案展示引用来源。
- 证据不足时明确说明。
- 支持一键打开来源笔记。
- 支持把问答沉淀成新笔记。
- 支持把当前对话整理进知识库。
- 支持轻量提示知识索引需要刷新。

推荐交互：

- 用户输入：“我之前关于 PowerSync 同步方案的判断是什么？”
- Agent 检索知识库并给出引用答案。
- 右侧展示相关笔记和摘录。
- 用户可以打开来源，也可以点击“沉淀为总结笔记”。
- 写入前展示笔记标题、路径和内容预览。
- 用户确认后写入知识库。

## 5. 第一阶段范围

第一阶段双线并行强化 Goal Agent 和 Knowledge Agent，但保持边界收敛。

### 5.1 首页与工作台

- 根路径 `/` 进入 AI Agent Workspace。
- `/ai/chat` 可保留为同一工作台入口或重定向目标。
- 移除传统欢迎页作为默认第一屏。
- 增加轻引导空状态和意图按钮。
- 保留会话列表和模型选择。

### 5.2 Goal Agent 强化

- 将目标创建作为第一类 Agent 工作流展示。
- 保持“草稿/计划 -> 确认 -> 执行”边界。
- 强化右侧目标草稿编辑体验。
- 强化执行计划和执行结果的可读性。
- 写入后提供打开目标、继续规划、生成复盘任务等后续动作。

### 5.3 Knowledge Agent 强化

- 在统一聊天工作台中启用“问知识库”意图。
- 知识问答返回答案和引用来源。
- 右侧展示引用来源列表和打开入口。
- 支持把本次问答整理成知识笔记。
- 支持“整理当前对话为知识笔记”。

### 5.4 非目标

第一阶段不做：

- 完全自动执行所有写入。
- 多 Agent 自主编排。
- 复杂权限、配额、计费体系。
- 新的独立知识库数据模型。
- 大规模重做所有业务模块页面。

## 6. 成功标准

产品体验成功标准：

- 用户打开应用后，第一眼能明确知道“我可以直接问/交给 Agent”。
- 用户能用一句自然语言创建目标草稿。
- 用户能在确认前看懂 Agent 将写入什么。
- 用户能基于个人知识库提问，并看到答案来源。
- 用户能把一次问答或对话沉淀为知识笔记。
- 页面看起来像 AI 原生工作台，而不是传统管理系统加了一个 AI 页面。

工程验收场景：

- 访问 `/` 后展示 AI Agent Workspace。
- 空会话状态展示主输入框和意图按钮。
- 创建目标流程能完成澄清、草稿、计划、确认、执行。
- 确认前不会创建真实目标、KR、任务或提醒。
- 知识问答展示 citations，并能打开对应知识来源。
- 知识库证据不足时展示明确提示。
- 刷新后可恢复会话和当前 Agent 上下文。
- 移动端可完成同样主流程。

## 7. 关键产品边界

- AI 是默认入口，但业务模块仍是数据真值。
- Agent 负责建议、草稿、计划和编排。
- Goal、Task、Repository、Reminder 等业务模块负责最终写入和数据一致性。
- 所有写入动作必须由用户确认。
- 知识问答必须展示依据，避免把普通聊天伪装成知识库问答。

## 8. 推荐实施顺序

1. 重构首页入口，把 `/` 指向 AI Agent Workspace。
2. 调整 AI Chat 空状态和底部输入区，使其成为主工作台。
3. 将工具菜单改为自然意图入口。
4. 强化 Goal Agent 右侧草稿、计划、确认和执行结果面板。
5. 启用 Knowledge Agent 问答入口，展示答案和引用来源。
6. 增加“沉淀为知识笔记”和“打开来源”动作。
7. 补齐桌面端、Web 端和移动端响应式验证。

## 9. 默认决策

- 产品风格：Claude 式工作台。
- 第一屏：轻引导 AI 工作台。
- Agent 优先级：Goal Agent 与 Knowledge Agent 双线并行。
- 写入边界：确认后执行。
- 知识问答入口：统一聊天工作台。
- 传统模块：保留为 Agent 产物管理面。
