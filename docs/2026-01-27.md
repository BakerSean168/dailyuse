标称类型”陷阱 (Nominal Typing)
TypeScript 的 Enum 是“标称类型”（Nominal）的
Interface/Type 是“结构类型”（Structural）

### 现代 TypeScript 的最佳替代方案

如果你既想要字面量的轻量，又想要 Enum 的“集中管理”和“自动补全”，请使用 **`as const` 对象**（这是目前 TypeScript 社区最推荐的模式）：

TypeScript

```
// 1. 定义常量对象 (替代 Enum)
export const DeviceType = {
  DESKTOP: 'DESKTOP',
  MOBILE: 'MOBILE',
  TABLET: 'TABLET',
  BROWSER: 'BROWSER',
  API: 'API',
  UNKNOWN: 'UNKNOWN',
} as const; // <--- 关键魔法：锁定为字面量类型

// 2. 提取类型 (自动生成联合类型)
// 结果等同于: 'DESKTOP' | 'MOBILE' | 'TABLET' ...
export type DeviceType = typeof DeviceType[keyof typeof DeviceType];

// 3. 在 DTO 中使用
export interface DeviceInfoClientDTO {
  deviceId: string;
  // 直接使用提取出来的字面量类型，既干净又规范
  deviceType: DeviceType; 
  // ...
}
```
