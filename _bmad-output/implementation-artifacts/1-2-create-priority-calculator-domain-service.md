### Existing Priority Calculator Analysis

**File:** `packages/domain-server/src/schedule/calculators/priority-calculator.ts`

**Current algorithm:**
```typescript
baseWeight = importanceWeight + urgencyWeight
timeWeight = based on dueDate proximity (0-5)
totalWeight = baseWeight + timeWeight
score = (totalWeight / 15) * 100
```

**Weight mappings:**
- Importance: vital=5, important=4, moderate=3, minor=2, trivial=1
- Urgency: critical=5, high=4, medium=3, low=2, none=1
- Time: overdue=+5, <1day=+4, <3days=+3, <7days=+2, <30days=+1

**What to reuse:**
- ✅ Importance weight concept (but adjust for new formula)
- ✅ Time-based weight calculation pattern
- ✅ Score normalization to 0-100 range
- ✅ Test patterns for edge cases

**What to change:**
- ❌ Remove urgency parameter completely
- ❌ New algorithm: `Priority = Importance * W1 + (1 / TimeRemaining) * W2`
- ❌ Different weight distribution (Story 1.3: W1=0.6, W2=0.4)
- ❌ Return simple number, not complex object

**Date Handling:**

- Convert to days: `ms / (24 * 60 * 60 * 1000)`
