## Story

As a 应用层开发者,
I want 在 `packages/application-server/src/task/services/` 中的 TaskQueryService 调用 PriorityCalculator，为每个任务计算优先级，并填充到 DTO,
So that API 返回的任务包含实时计算的优先级分数。

```typescript
// Application Layer (this story)
async function getTaskTemplate(uuid: string) {
  // 1. Query from repository (Infrastructure)
  const template = await repository.findById(uuid);
  
  // 2. Map to DTO
  const dto = template.toServerDTO();
  
  // 3. INJECT: Calculate priority (Domain Service)
  const priorityScore = calculatePriority(
    dto.importance,
    dto.dueDate, // or timeConfig.dueDate

  // 4. Enrich DTO with priority
```

```typescript
}
```

### Enrichment Function Design

**Recommended implementation:**
```typescript
// Helper function to enrich single DTO
function enrichWithPriority(
  dto: TaskTemplateServerDTO,
  currentTime: Date = new Date(),
): TaskTemplateServerDTOWithPriority {
  const priority = calculatePriority(
    dto.importance,
    extractDueDate(dto), // Extract from timeConfig or similar
    currentTime,
  );
  return {
    ...dto,
    priority,
  };
}

// Batch enrichment for performance
function enrichMultipleWithPriority(
  dtos: TaskTemplateServerDTO[],
  currentTime: Date = new Date(),
): TaskTemplateServerDTOWithPriority[] {
  return dtos.map(dto => enrichWithPriority(dto, currentTime));
}
```

### Performance Considerations

**Key concern:** N queries + N priority calculations

**Optimization techniques:**

1. **Batch Calculation:**
   - Enrich all tasks at once: O(n) instead of individual calculations
   - Already recommended in enrichMultipleWithPriority

2. **Lazy Calculation:**
   - Optional: Only calculate priority when explicitly requested
   - Parameter: `includeCalculatedPriority: boolean`

3. **Caching (Future):**
